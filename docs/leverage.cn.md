# 杠杆交易

!!! Note "同一账户上运行多个机器人"
    您不能在同一个账户上使用杠杆运行 2 个机器人。对于杠杆/保证金交易，freqtrade 假设它是该账户的唯一用户，所有清算水平都基于此假设计算。

!!! Danger "杠杆交易风险极高"
    不要使用大于 1 的杠杆交易，除非该策略在现货市场的实盘运行中已显示出正面结果。检查您策略的止损设置。使用 2 倍杠杆时，0.5（50%）的止损将太低，这些交易将在达到该止损之前被清算。
    我们不对使用本软件或此模式可能造成的任何损失承担责任。

    请仅在您了解 freqtrade（以及您的策略）如何工作时才使用高级交易模式。
    另外，永远不要冒超出您承受能力的风险。

如果您已有现有策略，请阅读[策略迁移指南](strategy_migration.md#strategy-migration-between-v2-and-v3)，将您的策略从 freqtrade v2 策略迁移到可以做空和交易期货的 v3 版本策略。

## 做空

在 [`trading_mode`](#leverage-trading-modes) 设置为 `spot` 时无法做空。要进行做空交易，`trading_mode` 必须设置为 `margin`（目前不可用）或 [`futures`](#futures)，并将 [`margin_mode`](#margin-mode) 设置为 [`cross`](#cross-margin-mode) 或 [`isolated`](#isolated-margin-mode)。

策略要进行做空交易，策略类必须设置类变量 `can_short = True`。

请阅读[策略自定义](strategy-customization.md#entry-signal-rules)了解如何设置信号以进入和退出做空交易。

## 理解 `trading_mode`

可选值为：`spot`（默认）、`margin`（*目前不可用*）或 `futures`。

### 现货（Spot）

常规交易模式（低风险）

- 仅限做多交易（不能做空）。
- 无杠杆。
- 无清算风险。
- 收益/损失等于资产价值的变化（减去交易手续费）。

### 杠杆交易模式

使用杠杆时，交易者从交易所借入资金。资金必须全额偿还给交易所（可能附带利息），交易者保留使用借入资金进行的任何交易的利润，或支付任何损失。

因为资金必须始终偿还，当杠杆账户中资产的总价值降至某个点（即总损失价值低于交易者在杠杆账户中实际拥有的抵押品价值的点）时，交易所将**清算**（强制出售交易者的资产）使用借入资金进行的交易，以确保交易者有足够的资金将借入的资产偿还给交易所。交易所还将收取**清算费用**，增加交易者的损失。

因此，**如果您不完全清楚自己在做什么，请不要使用杠杆交易。杠杆交易是高风险的，可能导致您的资产价值迅速降至 0，且没有再次增值的机会。**

#### 保证金交易（目前不可用）

交易在现货市场进行，但交易所按所选杠杆倍数借出等额的货币给您。您需要向交易所偿还借出的金额及利息，您的利润/损失按指定的杠杆倍数放大。

#### 期货（Futures）

永续合约（也称为永续期货）是以与其基础资产紧密挂钩的价格进行交易的合约。您交易的不是实际资产，而是衍生品合约。与期货或期权合约不同，永续合约可以无限期持续。

除了期货合约价格变化带来的收益/损失外，交易者还交换*资金费率*，这是基于期货合约和基础资产之间价格差异的收益/损失。期货合约和基础资产之间的价格差异因交易所而异。

要在期货市场交易，您需要将 `trading_mode` 设置为 "futures"。
您还需要选择一种"保证金模式"（说明见下文）。

``` json
"trading_mode": "futures",
"margin_mode": "isolated"
```

##### 交易对命名

Freqtrade 遵循 [ccxt 的期货命名约定](https://docs.ccxt.com/#/README?id=perpetual-swap-perpetual-future)。
期货交易对的命名格式为 `base/quote:settle`（例如 `ETH/USDT:USDT`）。

### 保证金模式（Margin mode）

除了 `trading_mode` 之外，您还需要配置 `margin_mode`。
虽然 freqtrade 目前只支持一种保证金模式，但这将会改变，现在配置好可以为未来的更新做好准备。

可选值为：`isolated` 或 `cross`。

#### 逐仓保证金模式（Isolated margin mode）

每个市场（交易对）的抵押品保存在独立的账户中。

``` json
"margin_mode": "isolated"
```

#### 全仓保证金模式（Cross margin mode）

使用一个账户在市场（交易对）之间共享抵押品。当需要时，从总账户余额中提取保证金以避免清算。

``` json
"margin_mode": "cross"
```

请阅读[交易所特定说明](exchanges.md)了解支持此模式的交易所及其差异。

!!! Warning "清算风险增加"
    全仓保证金模式会增加整个账户被清算的风险，因为所有交易共享相同的抵押品。
    一笔交易的损失可能影响其他交易的清算价格。
    此外，在模拟运行或回测模式下，跨仓位影响可能无法完全模拟。

## 设置使用的杠杆

不同的策略和风险配置需要不同级别的杠杆。
虽然您可以配置一个固定的杠杆值，但 freqtrade 提供了通过[策略杠杆回调](strategy-callbacks.md#leverage-callback)进行调整的灵活性——允许您按交易对使用不同的杠杆，或基于其他有利于策略结果的因素。

如果未实现，杠杆默认为 1x（无杠杆）。

!!! Warning
    更高的杠杆也意味着更高的风险——请确保您完全理解使用杠杆的含义！

## 理解 `liquidation_buffer`

*默认值为 `0.05`*

一个比率，指定在清算价格和止损之间放置多大的安全网，以防止仓位达到清算价格。
此人工清算价格的计算方式为：

`freqtrade_liquidation_price = liquidation_price ± (abs(open_rate - liquidation_price) * liquidation_buffer)`

- `±` = `+` 用于做多交易
- `±` = `-` 用于做空交易

可选值为 0.0 到 0.99 之间的任何浮点数

**例如：** 如果一笔交易以 10 coin/USDT 的价格入场，且该交易的清算价格为 8 coin/USDT，那么当 `liquidation_buffer` 设置为 `0.05` 时，该交易的最低止损为 $8 + ((10 - 8) * 0.05) = 8 + 0.1 = 8.1$

!!! Danger "`liquidation_buffer` 为 0.0 或较低的 `liquidation_buffer` 可能导致清算和清算费用"
    目前 Freqtrade 能够计算清算价格，但不计算清算费用。将 `liquidation_buffer` 设置为 0.0 或使用较低的 `liquidation_buffer` 可能导致您的仓位被清算。Freqtrade 不跟踪清算费用，因此清算将导致您的机器人的利润/损失结果不准确。如果您使用较低的 `liquidation_buffer`，建议在您的交易所支持的情况下使用 `stoploss_on_exchange`。

## 资金费率不可用

对于期货数据，交易所通常提供期货 K 线、标记价格和资金费率。然而，虽然 K 线和标记价格可能可用，但资金费率通常不可用。这可能会影响回测的时间范围，即您可能只能测试最近的时间范围而不是更早的时间范围，并遇到 `No data found. Terminating.` 错误。要解决这个问题，请添加 [configuration.md](configuration.md) 中列出的 `futures_funding_rate` 配置选项，建议将其设置为 `0`，除非您知道特定交易对、交易所和时间范围的具体资金费率。将其设置为 `0` 以外的值可能会对策略中的利润计算产生巨大影响，例如在 `custom_exit`、`custom_stoploss` 等函数中。

!!! Warning "这意味着您的回测结果将不准确。"
    这不会覆盖交易所提供的可用资金费率，但请注意，设置虚假的资金费率将意味着对于资金费率不可用的历史时间范围，回测结果将不准确。

### 开发者

#### 保证金模式

对于做空，支付借入货币利息费用的货币是在平仓交易的同时购买的（这意味着做空平仓交易中购买的金额大于做空开仓交易中卖出的金额）。

对于做多，支付借入货币利息费用的货币将已经由用户持有，不需要购买。利息从交易的 `close_value` 中扣除。

所有费用都包含在交易期间的 `current_profit` 计算中。

#### 期货模式

资金费用从交易的总金额中加上或减去。
