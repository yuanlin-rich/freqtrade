# 止损

`stoploss` 配置参数是应触发卖出的亏损比率。
例如，值 `-0.10` 将在给定交易的利润跌至 -10% 以下时立即卖出。此参数是可选的。
止损计算包含手续费，因此 -10% 的止损正好设置在入场价下方 10%。

大多数策略文件已经包含了最优的 `stoploss` 值。

!!! Info
    本文件中提到的所有止损属性都可以在策略或配置中设置。
    <ins>配置值将覆盖策略值。</ins>

## 交易所止损/Freqtrade 止损

这些止损模式可以是*交易所上的*或*交易所外的*。

这些模式可以通过以下值配置：

``` python
    'emergency_exit': 'market',
    'stoploss_on_exchange': False
    'stoploss_on_exchange_interval': 60,
    'stoploss_on_exchange_limit_ratio': 0.99
```

交易所止损仅支持以下交易所，且并非所有交易所都同时支持止损限价单和止损市价单。
如果仅有一种模式可用，订单类型将被忽略。

??? info "支持的交易所和止损类型"

    --8<-- "includes/exchange-features.md"

!!! Note "紧凑的止损"
    使用交易所止损时不要设置过低/过紧的止损值！
    如果设置过低/过紧，你将面临更大的订单未成交风险，止损将不起作用。

!!! Warning "宽松的止损"
    使用非常宽的止损（例如 -1）的交易所止损可能会由于交易所限制而无法在交易所上下达止损订单。
    在这种情况下，机器人将回退使用 `emergency_exit` 订单类型下达市价单，因为下达止损订单失败。
    Freqtrade 目前没有实现避免此情况的限制，因此请确保你的止损值在交易所的合理范围内，或禁用交易所止损。

### 交易所止损使用哪种订单类型？

交易所止损使用的订单类型由 `stoploss` 值和交易所能力决定。
如果你选择的交易所同时支持止损限价单和止损市价单，则 `stoploss` 值将决定交易所止损使用哪种订单类型。
如果你的交易所只支持两种订单类型中的一种，你必须相应地配置 `stoploss` 值，否则机器人将无法启动。

### 交易所止损应该使用哪种订单类型？

如果我们将两种止损订单类型翻译成通俗的语言，它们大致如下：

* **stoploss-market** -> "当止损触发时，以任何价格让我立即离场"。
* **stoploss-limit** -> "当止损触发时，在止损价下方 x% 处下一个限价单。我最多接受 'stoploss + 1%' 的亏损——但如果价格跳得更远——我接受等待价格回落到我的位置，可能导致比 'stoploss + 1%' 大得多的亏损"。

因此，我们建议尽可能使用止损市价单，因为止损的主要目的是在市场崩盘时让你退出仓位，在这种情况下，你会希望以最佳可用价格立即退出仓位，而不是冒限价单未成交的风险并可能遭受更大的损失。
选择最终取决于你，但请注意使用止损限价单的风险，尤其是在波动市场中。

### stoploss_on_exchange 和 stoploss_on_exchange_limit_ratio

启用或禁用交易所止损。
如果止损是*在交易所上的*，这意味着在买入订单成交后立即在交易所上下达一个止损限价单。这将保护你免受市场突然崩盘的影响，因为订单执行完全在交易所内部进行，没有潜在的网络延迟。

如果 `stoploss_on_exchange` 使用限价单，交易所需要 2 个价格：stoploss_price 和限价。
`stoploss` 定义了限价单下达时的止损触发价——而限价应略低于此价格。
如果交易所同时支持限价和市价止损订单，则 `stoploss` 的值将用于确定止损类型。

计算示例：我们以 100$ 买入资产。
止损触发价为 95$，则限价为 `95 * 0.99 = 94.05$`——所以限价单成交可以在 95$ 和 94.05$ 之间发生。

例如，假设止损在交易所上，并且启用了追踪止损，且市场正在上涨，则机器人会自动取消之前的止损订单，并下一个止损值高于之前止损订单的新订单。

!!! Note
    如果 `stoploss_on_exchange` 已启用，且止损在交易所上被手动取消，则机器人将创建一个新的止损订单。

### stoploss_on_exchange_interval

对于交易所止损，还有一个名为 `stoploss_on_exchange_interval` 的参数。这配置了机器人检查止损并在必要时更新的间隔（以秒为单位）。
机器人不能每 5 秒（每次迭代）执行此操作，否则会被交易所封禁。
因此此参数将告诉机器人应多久更新一次止损订单。默认值为 60（1 分钟）。
如果你不小心取消了止损订单，同样的逻辑将在交易所上重新应用止损订单。

### stoploss_price_type

!!! Warning "仅适用于期货"
    `stoploss_price_type` 仅适用于期货市场（在可用的交易所上）。
    Freqtrade 将在启动时验证此设置，如果为你的交易所选择了无效设置将无法启动。
    支持的价格类型因交易所而异。请向你的交易所确认其支持哪些价格类型。
    在现货市场中，此设置被忽略且不验证，因为大多数交易所在现货市场的止损订单仅支持一种价格类型。

期货市场的交易所止损可以在不同的价格类型上触发。
这些价格在交易所术语中的命名通常各不相同，但通常是 "last"（或 "contract price"）、"mark" 和 "index" 之类的东西。

此设置的可接受值为 `"last"`、`"mark"` 和 `"index"`——freqtrade 将自动转换为相应的 API 类型，并相应地下达 [交易所止损](#stoploss_on_exchange-and-stoploss_on_exchange_limit_ratio) 订单。

### force_exit

`force_exit` 是一个可选值，默认与 `exit` 相同的值，在从 Telegram 或 Rest API 发送 `/forceexit` 命令时使用。

### force_entry

`force_entry` 是一个可选值，默认与 `entry` 相同的值，在从 Telegram 或 Rest API 发送 `/forceentry` 命令时使用。

### emergency_exit

`emergency_exit` 是一个可选值，默认为 `market`，在创建交易所止损订单失败时使用。
以下是如果未在策略或配置文件中更改时使用的默认值。

策略文件示例：

``` python
order_types = {
    "entry": "limit",
    "exit": "limit",
    "emergency_exit": "market",
    "stoploss": "market",
    "stoploss_on_exchange": True,
    "stoploss_on_exchange_interval": 60,
    "stoploss_on_exchange_limit_ratio": 0.99
}
```

## 止损类型

在当前阶段，机器人包含以下止损支持模式：

1. 静态止损。
2. 追踪止损。
3. 追踪止损，自定义正收益止损。
4. 仅在交易达到特定偏移量后才追踪止损。
5. [自定义止损函数](strategy-callbacks.md#custom-stoploss)

### 静态止损

这非常简单，你定义一个 x 的止损（作为价格比率，即 x * 100% 的价格）。一旦亏损超过定义的亏损值，将尝试卖出资产。

止损示例：

``` python
    stoploss = -0.10
```

例如，简化计算：

* 机器人以 100$ 的价格买入资产
* 止损定义为 -10%
* 一旦资产跌破 90$，止损将被触发

### 追踪止损

此功能的初始值是 `stoploss`，就像你定义静态止损一样。
要启用追踪止损：

``` python
    stoploss = -0.10
    trailing_stop = True
```

这将激活一个算法，每当资产价格上涨时自动上移止损。

例如，简化计算：

* 机器人以 100$ 的价格买入资产
* 止损定义为 -10%
* 一旦资产跌破 90$，止损将被触发
* 假设资产现在涨到 102$
* 止损现在将是 102$ 的 -10% = 91.8$
* 现在资产跌到 101$，止损仍然是 91.8$，将在 91.8$ 触发。

总结：止损将被调整为始终是最高观察价格的 -10%。

### 追踪止损，不同的正收益止损

你也可以在买入亏损时（买入价 - 手续费）设置默认止损，但一旦达到正收益结果（或你定义的偏移量），系统将使用新的止损，具有不同的值。
例如，你的默认止损是 -10%，但一旦你达到盈利（例如 0.1%），将使用不同的追踪止损。

!!! Note
    如果你希望止损仅在保本或盈利时才改变（这是大多数用户想要的），请参阅下一节的 [启用偏移量](#trailing-stop-loss-only-once-the-trade-has-reached-a-certain-offset)。

两个值都要求 `trailing_stop` 设置为 true，且 `trailing_stop_positive` 有一个值。

``` python
    stoploss = -0.10
    trailing_stop = True
    trailing_stop_positive = 0.02
    trailing_stop_positive_offset = 0.0
    trailing_only_offset_is_reached = False  # Default - not necessary for this example
```

例如，简化计算：

* 机器人以 100$ 的价格买入资产
* 止损定义为 -10%
* 一旦资产跌破 90$，止损将被触发
* 假设资产现在涨到 102$
* 止损现在将是 102$ 的 -2% = 99.96$（99.96$ 的止损将被锁定，并以 -2% 跟随资产价格上涨）
* 现在资产跌到 101$，止损仍然是 99.96$，将在 99.96$ 触发

0.02 将转换为 -2% 的止损。
在此之前，`stoploss` 用于追踪止损。

!!! Tip "使用偏移量更改止损"
    使用 `trailing_stop_positive_offset` 确保新的追踪止损已经处于盈利状态，方法是将 `trailing_stop_positive_offset` 设置得高于 `trailing_stop_positive`。你的第一个新止损值将已经锁定了利润。

    简化计算示例：

    ``` python
        stoploss = -0.10
        trailing_stop = True
        trailing_stop_positive = 0.02
        trailing_stop_positive_offset = 0.03
    ```

    * 机器人以 100$ 的价格买入资产
    * 止损定义为 -10%，所以一旦资产跌破 90$ 止损将被触发
    * 假设资产现在涨到 102$
    * 止损现在将在 91.8$——最高观察价格下方 10%
    * 假设资产现在涨到 103.5$（超过配置的偏移量）
    * 止损现在将是 103.5$ 的 -2% = 101.43$
    * 现在资产跌到 102$，止损仍然是 101.43$，一旦价格跌破 101.43$ 将触发

### 仅在交易达到特定偏移量后才追踪止损

你也可以在达到偏移量之前保持静态止损，然后在市场转向时追踪交易以获利。

如果 `trailing_only_offset_is_reached = True`，则追踪止损仅在达到偏移量后才激活。在此之前，止损保持在配置的 `stoploss` 值，不进行追踪。
将此值保留为 `trailing_only_offset_is_reached=False` 将允许追踪止损在资产价格超过初始入场价后立即开始追踪。

此选项可以与或不与 `trailing_stop_positive` 一起使用，但使用 `trailing_stop_positive_offset` 作为偏移量。

配置（偏移量为买入价 + 3%）：

``` python
    stoploss = -0.10
    trailing_stop = True
    trailing_stop_positive = 0.02
    trailing_stop_positive_offset = 0.03
    trailing_only_offset_is_reached = True
```

例如，简化计算：

* 机器人以 100$ 的价格买入资产
* 止损定义为 -10%
* 一旦资产跌破 90$，止损将被触发
* 除非资产涨到或超过配置的偏移量，止损将保持在 90$
* 假设资产现在涨到 103$（我们配置偏移量的位置）
* 止损现在将是 103$ 的 -2% = 100.94$
* 现在资产跌到 101$，止损仍然是 100.94$，将在 100.94$ 触发

!!! Tip
    确保此值（`trailing_stop_positive_offset`）低于最小 ROI，否则最小 ROI 将先行适用并卖出交易。

## 止损与杠杆

止损应该被理解为"此笔交易的风险"——因此 100$ 交易中 10% 的止损意味着你愿意在此笔交易中亏损 10$（10%）——如果价格向下移动 10% 将触发。

使用杠杆时，同样的原则适用——止损定义的是交易风险（你愿意亏损的金额）。

因此，10 倍交易中 10% 的止损将在 1% 的价格移动时触发。
如果你的投入金额（自有资金）是 100$——在 10 倍杠杆下此交易将是 1000$。
如果价格移动 1%——你已经亏损了 10$ 的自有资金——因此在这种情况下止损将触发。

请确保了解这一点，避免使用过紧的止损（在 10 倍杠杆下，10% 的风险可能太少，不足以让交易有一定的"喘息"空间）。

## 更改已开仓交易的止损

可以通过更改配置或策略中的值并使用 `/reload_config` 命令来更改已开仓交易的止损（或者完全停止并重新启动机器人也可以）。

新的止损值将应用于已开仓交易（并生成相应的日志消息）。

### 限制

如果 `trailing_stop` 已启用且止损已被调整过，则止损值无法更改。
