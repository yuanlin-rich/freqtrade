## 如何更新

与往常一样，你可以使用以下命令之一更新你的机器人：

### docker-compose

```bash
docker-compose pull
docker-compose up -d
```

### 通过安装脚本安装

``` bash
# 退出虚拟环境并运行
./setup.sh --update
```

### 原生安装

``` bash
git pull
pip install -U -r requirements.txt
```
